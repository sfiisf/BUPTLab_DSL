# BUPT 程序设计实践课程期末大作业
## 内容
实现一个领域特定语言（Domain Specific Language，DSL），根据提供的文法实现在线客服机器人自动应答功能，详细要求见`./要求.txt`，详细介绍见`./实验报告.pdf`
## 文件说明
```
-expected_output // 自动测试期望输出文件夹
-input // 自动测试输入文件夹
-output // 自动测试输出文件夹
-stub // 测试桩文件夹
-syntax // 语法文件文件夹
auto_test.bat // 自动测试脚本
Automaton.cpp // 程序源代码自动机实现部分
DSL.cpp // 程序源代码，main函数实现部分
Syntax.cpp // 程序源代码，语法树实现部分
Syntax.h // 程序源代码头文件
实验报告.pdf // 实验报告
```
## 其他
使用`cpp`实现，实现从设计到完成花费时间约为`2~3`天，难度评价为较易。

完成时间`2024-12-17`
